# 星轨回收者 · Orbit Salvage

一个**零依赖、单文件**的街机风小游戏：操纵回收艇环绕恒星，在四条环形轨道上回收星尘、躲避陨石与猎手，撑过 8 波即通关。

---

## 1. 游戏定位

| 项目 | 说明 |
|------|------|
| **游戏类型** | 休闲动作 / 街机生存（Wave Survival + 收集） |
| **核心机制** | 极坐标轨道移动——只能沿圆环切向跑与径向换道，无法自由飞行 |
| **单局时长** | 约 3～6 分钟（8 波） |
| **目标运行平台** | 现代浏览器（Chrome / Edge / Safari / Firefox），桌面键鼠 + 移动端触屏 |
| **技术形态** | 单个 `index.html`（原生 Canvas 2D + Web Audio API），零外部依赖、零构建 |
| **附加启动方式** | `serve.py`（Python 3 标准库静态服务器，可选） |

## 2. 运行方法

**方式 A（最简单）**：直接双击 `index.html`，或把文件拖进浏览器。

**方式 B（推荐，最高分持久化更稳）**：

```bash
cd orbit-salvage
python3 serve.py            # 默认 http://127.0.0.1:8000 并自动打开浏览器
python3 serve.py -p 5173    # 换端口
```

## 3. 操作方式

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 沿轨道逆时针 | `←` / `A` | `◀` |
| 沿轨道顺时针 | `→` / `D` | `▶` |
| 切换到内侧轨道 | `↑` / `W` | `▲` |
| 切换到外侧轨道 | `↓` / `S` | `▼` |
| 释放脉冲冲击波 | `空格` | `⚡` |
| 暂停 / 继续 | `P` / `Esc` | 右上按钮 |
| 静音 | `M` | 右上按钮 |
| 重开 | `R` | 结算面板按钮 |

> 手感设计：角速度 = 恒定线速度 ÷ 当前半径，所以内圈转得快、外圈转得慢，四条轨道的移动手感一致。

## 4. 核心玩法规则

- **场地**：中央恒星核心 + 4 条同心环形轨道，敌人从屏幕外沿半径向内飞。
- **星尘（绿色菱形）**：分布在随机轨道与角度上，飞过去即可回收。
- **陨石（橙色石块）**：直线冲向核心，撞到玩家 **-1 护盾**，撞到核心 **-1 核心 HP**。
- **猎手（红色战机，第 3 波起出现）**：会缓慢追踪你所在的角度，威胁更高，脉冲击毁得分更多。
- **脉冲冲击波（空格）**：能量满 100% 后释放，从核心向外扩散的环形冲击波，摧毁环带上的所有敌人。

## 5. 得分与进度系统

| 事件 | 得分 |
|------|------|
| 回收 1 颗星尘 | `10 × 连击倍率` |
| 脉冲摧毁陨石 | `+15` |
| 脉冲摧毁猎手 | `+35` |
| 完成一波 | `+50 × 波次` |

- **连击**：连续回收星尘累积连击数，每 5 连提升 0.5 倍率，最高 **×4**；受伤或被击中核心即清零。
- **能量**：回收星尘 +9%，脉冲击毁 +6～8%，满 100% 可释放冲击波。
- **波次推进**：清空当前波的全部星尘即进入下一波，敌人更快更密；每 3 波额外回复 1 点护盾。

## 6. 胜利 / 失败判定

- **胜利**：完成第 8 波 → "轨道净化完成"，可选再来一局或进入**无尽挑战**（难度持续上升）。
- **失败**：护盾耗尽（初始 3 点），或恒星核心被击穿（初始 5 点 HP）。
- **重玩**：结算面板按钮、`R` 键或 `Enter` 键均可立即重开；最高分保存在浏览器 `localStorage`。

## 7. 反馈表现

- **视觉**：霓虹辉光与引擎尾焰、粒子爆炸、轨道高亮、屏幕震动、核心受损闪红、回收飘字、波次横幅、受损时飞船闪烁无敌帧。
- **音效**：Web Audio 程序化实时合成（无音频文件）——回收音随连击升调、撞击噪声爆、脉冲扫频、核心受损低频、波次琶音、失败下行音阶、通关上行音阶。`M` 键可静音。

## 9. 已知边界

- `file://` 直接打开时，个别浏览器会禁用 `localStorage`，最高分可能无法保存（用 `serve.py` 即正常）。
- 首次发声需要一次用户交互（点击/按键），这是浏览器音频策略限制，已通过开始按钮自动解锁。
- 难度曲线在无尽模式下会持续上升，没有上限。
